# Portfolio Website - Muhammad Dilawar

A responsive personal portfolio website showcasing my projects, skills, education, and experience. Built to apply for Frontend Development Internships.


---

## Features

- Dark / Light mode toggle
- Typing animation in hero section
- Fully responsive (mobile, tablet, desktop)
- Mobile hamburger menu
- Scroll reveal animations
- Animated skill progress bars
- Contact form validation
- Project showcase with images and links

---

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts

---

## How to Run Locally

```bash
git clone https://github.com/devdilawar/portfolio-website.git
cd portfolio-website
```

Open `index.html` in your browser.
